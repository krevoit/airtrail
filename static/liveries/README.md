# Airline liveries

Side views of aircraft in airline paint schemes (85 × 20 px), from the
operator flags of [rikgale/VRSOperatorFlags](https://github.com/rikgale/VRSOperatorFlags)
(commit `c4b2083`), licensed under the GNU General Public License v3.0.
Airline names, logos and liveries belong to their owners.

Regenerate with `node scripts/data/generate-liveries.js`.
